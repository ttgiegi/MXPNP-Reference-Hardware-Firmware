All SVGs have transparent backgrounds and outlined lettering. They contain native vector paths without embedded bitmaps, external fonts, gradients or filters. Primary color: `#173B4B`; monochrome: `#000000`; reversed: `#FFFFFF`.

The README and Wiki use the primary version on light backgrounds and the reversed version on dark backgrounds. Use monochrome exports for PCB silkscreen or engraving, and check the letter openings at the intended manufacturing size.

These are approved exports of the C02 master maintained in the MXPNP application repository. They provide project identity; hardware status, compatibility and upstream attribution remain documented with each archived design.
